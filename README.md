# Result School — JavaScript

Учебный репозиторий по JavaScript: массивы, объекты, контекст `this`, классы, ООП и работа с DOM.

## Финальный проект модуля «Основы OOP и DOM»

[Quiz Renderer](./quiz-renderer/) — универсальный MVC-рендерер тестов на чистых HTML, CSS и JavaScript.

Возможности проекта:

- четыре типа вопросов;
- навигация и проверка обязательных ответов;
- подсчёт баллов и подробный разбор;
- сохранение прогресса в `localStorage`;
- история последних попыток;
- модульные тесты модели.

Инструкция по запуску и описание архитектуры находятся в
[quiz-renderer/README.md](./quiz-renderer/README.md).
